# 画面与操作设置推荐

* TOC
{:toc}

## 画面设置

| 选项 | 推荐值 | 原因 |
| --- | --- | --- |
| 动态模糊 | 关闭 | 影响判定视野，对打 BOSS 无益 |
| 阴影质量 | 中 | 高与中的视觉差异极小，帧数差异明显 |
| 粒子效果 | 低 | 大量粒子会遮挡 BOSS 的起手动作 |
| 垂直同步 | 开启 | 撕裂会干扰翻滚时机判断 |

## 操作设置

- **翻滚键**改到肩键。默认的按键位置会让右手同时负担攻击和闪避，在连招中容易误触。
- **锁定切换**建议关掉自动锁定，改为手动。自动锁定在被包围时会把视角甩到错误的敌人身上。
- **镜头灵敏度**保持在 5 左右。太高会在翻滚后甩过头。

## 存档与备份

设置文件位于游戏安装目录下的 `settings.ini`。换机器时直接复制这个文件即可，
不需要重新调一遍。

{: .tip }
调完设置之后先打一场杂兵再进 BOSS 房，确认手感没有变化。
